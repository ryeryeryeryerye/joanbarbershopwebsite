# 2. Sơ Đồ Thiết Kế Hệ Thống (Diagrams)

Thư mục chứa sơ đồ thiết kế hệ thống:
- Sơ đồ ca sử dụng tổng quan (Use Case Diagram).
- Sơ đồ thực thể - mối quan hệ cơ sở dữ liệu (ERD - Entity Relationship Diagram).
- Sơ đồ tuần tự (Sequence Diagram cho luồng Đăng nhập, Đặt lịch, Phân công ca).
- Sơ đồ hoạt động (Activity Diagram).
