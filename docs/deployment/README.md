# 8. Hướng Dẫn Triển Khai (Deployment)

Thư mục lưu trữ:
- Quy trình chuẩn bị biến môi trường Production.
- Cấu hình Build tối ưu cho Frontend (Vite bundle optimization).
- Cấu hình chạy Production cho Backend (Process Manager / PM2, Docker containerization).
- Hướng dẫn kết nối cơ sở dữ liệu MongoDB Atlas trực tuyến.
