# Tài Liệu Dự Án BARBERSHOP

Thư mục chứa toàn bộ tài liệu kỹ thuật, phân tích nghiệp vụ, thiết kế và hướng dẫn triển khai của dự án **BARBERSHOP – Website quản lý và đặt lịch cắt tóc trực tuyến**.

## Cấu trúc thư mục tài liệu

- [requirements/](./requirements/): Phân tích nghiệp vụ, danh sách chức năng (Use Cases), User Stories và yêu cầu phi chức năng.
- [diagrams/](./diagrams/): Sơ đồ thiết kế hệ thống (Use Case Diagram, ERD - Entity Relationship Diagram, Sequence Diagrams, Architecture Flow).
- [wireframes/](./wireframes/): Bản phác thảo giao diện cấu trúc (Low-fidelity wireframes cho PC và Mobile).
- [mockups/](./mockups/): Thiết kế giao diện chi tiết (High-fidelity mockups, Design System, Color Palette, Typography).
- [architecture/](./architecture/): Kiến trúc phần mềm Monorepo, Feature-based Pattern, sơ đồ phân tầng Backend.
- [api/](./api/): Đặc tả kỹ thuật RESTful API (Endpoints, Request/Response payloads, mã lỗi, authentication header).
- [testing/](./testing/): Kế hoạch kiểm thử (Test Plan, Test Cases, Unit Testing & Integration Testing Checklist).
- [deployment/](./deployment/): Hướng dẫn cấu hình môi trường Production, Docker, CI/CD và triển khai Hosting/Cloud.
- [user-guide/](./user-guide/): Tài liệu hướng dẫn sử dụng cho Khách hàng (Customer), Thợ cắt tóc (Barber) và Quản trị viên (Admin).
