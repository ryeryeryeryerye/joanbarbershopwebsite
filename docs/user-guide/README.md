# 9. Hướng Dẫn Sử Dụng & Báo Cáo (User Guide & Project Report)

Thư mục lưu trữ:
- Hướng dẫn thao tác dành cho Khách hàng (Đặt lịch, quản lý lịch hẹn, hủy/đổi lịch).
- Hướng dẫn thao tác dành cho Thợ cắt tóc (Xem ca trực, xác nhận lịch hẹn).
- Hướng dẫn thao tác dành cho Quản trị viên (Quản lý hệ thống, thống kê báo cáo).
- File báo cáo đồ án hoàn chỉnh.
